## 🏗️ Les 7 Univers

1. **U1 — La Famille** : Registre, arbre généalogique, branches, rôles
2. **U2 — La Vie familiale** : Calendrier, événements, moteur workflow automatisé
3. **U3 — La Solidarité** : Dossiers, collectes, suivi, équité, transparence
4. **U4 — Les Finances** : Caisse, cotisations, Mobile Money, comptabilité
5. **U5 — La Gouvernance** : Votes, comités, élections, règlement, PV
6. **U6 — La Mémoire** : Bibliothèque, albums, anciens, traditions
7. **U7 — Le Réseau** : Compétences, entraide, mentorat, diaspora

## 📊 Chiffres clés

- **7 univers** spécifiés en détail (~46 000 mots)
- **52 tables** PostgreSQL définies
- **121 notifications** cataloguées
- **70 scénarios** de test
- **MVP en 9 mois** (U1 + U4 + Mobile Money)
